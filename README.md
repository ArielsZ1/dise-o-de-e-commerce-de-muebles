# Fábrica a tu Casa · MVP (Maderas del Norte S.A.)

Prototipo demostrativo con datos y precios ficticios.

## Cómo abrirlo en Visual Studio Code
1. Descomprimí la carpeta y abrila en VS Code (Archivo > Abrir carpeta).
2. Instalá la extensión **Live Server** (Ritwick Dey).
3. Clic derecho sobre `index.html` > **Open with Live Server**.
   (Alternativa sin extensión: abrir `index.html` con doble clic en el navegador.)

## Archivos
- `index.html`: estructura de las 4 pantallas (Tienda, Chatbot, Automatización, Panel y QR).
- `styles.css`: estilos.
- `app.js`: datos de ejemplo y lógica (carrito, chatbot, flujo de pedido, KPIs, QR ilustrativo).

## Equivalencias con la solución real
Tienda = e-commerce + pasarela de pago · Chatbot = ManyChat · Automatización = n8n · QR = QR dinámico.
